Welcome to the central repository for **Tasks 1, 2, and 3** of the DevOps & Automation Lab (ENSP461).

This project demonstrates the implementation of a fully automated Continuous Integration and Continuous Deployment (CI/CD) pipeline using Jenkins, Git, and Nginx.

## 📂 Repository Contents
- `index.html`: The static website's main HTML file.
- `style.css`: The stylesheet for the website.
- `Jenkinsfile`: The declarative pipeline script that defines the Build, Test, and Deploy stages.

## 🎯 Overview of Lab Tasks
- **Task 1 & 2:** Configuration of a Jenkins pipeline that automatically pulls source code from this repository, validates it through testing, and deploys the static website using an Nginx web server.
- **Task 3:** The foundational installation and configuration of Git, Jenkins LTS, and Nginx, including connecting the Jenkins controller to this GitHub repository.
